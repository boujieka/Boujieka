Recherche du 26/10/2026. Statuts : **V** = vérifié dans la source citée · **C** = sources en désaccord
· **N** = non vérifié. Les codes de source (`[TMP]`, `[ARCE]`…) renvoient à

## 2. Architecture (TMP)

Axe **rectiligne**, orienté env. 290° (vers l'ouest, dans la montagne). Longueur totale : **non publiée
dans les sources ouvertes** (somme des longueurs TMP ≈ 117 m, calcul personnel → écrire « plus de cent
mètres », formule de [SIP]).

| Salle | Description | Décor principal |
|---|---|---|
| **A** | Entrée | — |
| **Porte B** | Disque solaire avec scarabée et dieu à tête de bélier, entre Isis et Nephthys ; noms de Ramsès V regravés en Ramsès VI | V [TMP] |
| **B** | Corridor 1 | Sud : le roi (à l'origine Ramsès V) devant Rê-Horakhty et Osiris, puis **Livre des Portes** div. 1-2 (Piankoff) ; Nord : **Livre des Cavernes** div. 1 ; plafond : constellations circumpolaires et décans |
| **C** | Corridor 2 | Sud : Portes div. 3-5, dont la **salle du jugement d'Osiris** (5ᵉ porte) ; Nord : Cavernes div. 2-début 3 ; plafond astronomique |
| **D** | Corridor 3 | Sud : Portes div. 6-7 ; niche sud : extraits du **Livre de la Vache céleste** ; Nord : Cavernes div. 3-4-début 5 ; plafond : jambes de Nout sur le début du Livre du Jour et la fin du Livre de la Nuit |
| **E** | Salle (inachevée, pas de puits) — **fin du chantier de Ramsès V** | Portes div. 8-9 ; Cavernes div. 5 ; plafond : Jour et Nuit |
| **F** | Salle à 4 piliers (8,44 × 7,22 m) avec descente centrale | Sud : Portes div. 10-12 et scène finale ; Nord + pilier 4 : Cavernes div. 6 ; Ouest : le roi encense et libe devant Osiris ; piliers : le roi avec Khonsou, Amon-Rê, Meretseger, Ptah-Sokar-Osiris, Rê-Horakhty, Ptah, Thot ; plafond : tête et bras de Nout, horloges stellaires et décans sur les côtés |
| **Descente F** | | Nekhbet (cobra ailé), **Amdouat** heure 1, Neith ; Meretseger, Amdouat heure 6, Serket ; trois vautours |
| **G** | Corridor | Sud : Amdouat 1-3 ; Nord : Amdouat 6-8 ; plafond : barques solaires, momies sur lits ; deux trous de poutre (peut-être pour descendre le sarcophage) |
| **H** | Corridor | Sud : Amdouat 4-5 ; Nord : Amdouat 8-11 ; plafond : **scènes cryptographiques** |
| **I** | Antichambre | **Livre des Morts** 124, 125, 127, 129 (126 : **N**, seulement Wikipédia) ; le roi devant Heka, adoration de Maât, hymne à Maât, le roi devant deux bassins avec babouins (« lacs de feu ») ; plafond : résurrection d'Osiris (cryptographique) |
| **J** | **Chambre funéraire** voûtée, 4 piliers à l'avant (1ᵉʳ et 4ᵉ jamais dégagés), plus petite que prévu | **Livre de la Terre** : partie A paroi nord, B-C paroi ouest, D paroi sud, E pilastre ouest ; ennemis ligotés sur toutes les parois ; voûte : **deux Nout dos à dos** encadrant les Livres du Jour et de la Nuit ; piliers : le roi avec Maât, Ptah-Sokar, Anubis, Meretseger, Osiris, Ptah |
| **K** | Fin de l'axe, jamais achevée | **Scène finale du Livre des Portes** : Noun soulève la barque de Rê ; le roi agenouillé ; décans en adoration |

Absent de KV9 : **Litanie de Rê** (V, [TMP-FC]) ; **Livre de Nout** (V, [TMP-FC] : seulement Osireion et KV2).
Hypothèse : programme copié sur l'**Osireion d'Abydos** (Herzer 2023) — **N** / thèse isolée, ne pas
présenter comme établie.
