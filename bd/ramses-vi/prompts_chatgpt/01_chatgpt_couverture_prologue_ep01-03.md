# Prompts ChatGPT — Couverture, prologue, épisodes 1 à 3

Un prompt par **planche**, à coller dans ChatGPT **après** le « Brief de série » et les « Fiches
personnages » (voir `00_mode_d_emploi_chatgpt.md`). Scripts sources : `01_couverture.md`,
`02_prologue.md`, `03_episode_01_la_porte_de_kv9.md`, `04_episode_02_le_plafond_des_etoiles.md`,
`05_episode_03_le_livre_sans_commencement.md`.

**Rappels propres à ce fichier**

- Les zones du tombeau suivent les lettres du **Theban Mapping Project** (TMP) : B, C, D = corridors 1 à 3 ;
  F = salle à piliers ; J = chambre funéraire. Ces lettres ne doivent **jamais** apparaître dans l'image.
- Les parois réelles sont décrites volontairement de façon sobre (« registres peints de figures… ») :
  ChatGPT les inventera de toute façon. Toute case listée sous « ⚠ Références » doit être **redessinée ou
  corrigée d'après la source indiquée** avant publication.
- **Personnages historiques réels** (Howard Carter, Alexandre Piankoff, L. F. Husson) : de dos, de trois
  quarts dos ou en silhouette, sans ressemblance. Natacha Rambova n'apparaît pas sur place.
- **Liseré doré** : style B (mythologique) et style C (reconstitution historique) uniquement. Quand le
  script le fait « apparaître une seconde » sur une case contemporaine, on demande seulement une lueur
  dorée au bord du cadre.
- Tous les textes (cartouches, bulles, SFX, écrans, plaques, titres, dates) sont posés **au lettrage**.
