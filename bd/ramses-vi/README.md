## Convention de balisage

Chaque élément du scénario porte une balise :

- **[H] Histoire documentée** — vérifiable dans une source publiée (la source est indiquée ou marquée `À VÉRIFIER`).
- **[F] Fiction narrative** — personnages contemporains, dialogues, mission scientifique, péripéties.
- **[S] Symbolisme / interprétation** — lecture philosophique ou spirituelle, présentée comme telle, jamais comme un fait.

Toute mention `À VÉRIFIER` doit être levée (source primaire ou publication d'égyptologue) **avant l'impression**.
