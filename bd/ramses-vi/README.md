## Convention de balisage

- **[H] Histoire documentée** : vérifiable dans une source publiée, référencée dans la bible.
- **[F] Fiction narrative** : personnages contemporains, dialogues, mission scientifique.
- **[S] Symbolisme / interprétation** : lecture philosophique, présentée comme telle.

Statuts de vérification : **V** vérifié · **C** sources en désaccord · **N** non vérifié.
