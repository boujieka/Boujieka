* The chain is present but implicit. It is not drawn anywhere, and valuation has no chapter of its own (it appears in Chapters 9, 15 and 16).

* The book has a small number of figures. Most chapters are text and tables only.

## 3. Model architecture (v0.7)

44 sheets, all visible. 99,438 formulas. No defined names. No external links. A full evaluation with an independent formula engine (October 2026) found no error values in 125,769 evaluated cells. The master check reads OK at default inputs. The file is written without cached values and is set to recalculate on opening, so its behaviour in Microsoft Excel and LibreOffice has not yet been tested. LibreOffice is installed in this environment, so a headless recalculation test is possible in Phase 13.

Largest calculation sheets by formula count: Vintage_Engine 17,980; Credit_Engine 16,010; Ops 8,966; Cohort_T1 to T5 7,740 each; Curves 3,685; FS 3,593; RBF_Engine 2,214.

Main flow: Inputs, Products and Scenarios feed Timeline and Curves. Curves and Ops drive the cohort sheets and the credit and RBF engines. Costs and Financing complete FS. FS feeds Annual, KPIs, Covenants and Valuation. Those feed Investment_Summary, Investment_Readiness and the Cover status panel.

Front-end observations:

* Dashboard is a thin sheet (charts plus two status cells).
* Sensitivity holds 147 static values computed outside the workbook. They are labelled as static, but they do not update when inputs change.
* The Contents index is not in tab order and lists only one cohort sheet.
* There are no named ranges, so key outputs are referenced by cell address only.

## 5. Critical issues, ranked

1. **M-KOPA evidence comes from the wrong entity.** The only primary filing provided is a GBP subsidiary with GBP 1.7m revenue. The USD 416m and USD 253.5m figures remain secondary and unreconciled, and the Calibration sheet uses a net margin derived from them. Severity: high (a flawed benchmark in the model and the book).
2. **KPI standard is out of date.** The book and model frame PERFORM on the 2021 guide. The model's headline credit metric is a collection rate (collected divided by due, excluding deposits), and its Vintage_Dashboard shows a "repayment rate" that is not built to the 2026 rules (daily linearisation, applied payments, PvP and PvFin bases, @90 Days and @2x horizons). The 2026 guide expressly says a collection rate must not be used as a substitute for the Repayment Rate. Severity: high.
3. **Two unverified sector facts are used prominently.** The 62% collection rate (E1) and the BBOXX administration date (E7) both appear in the opening chapter, and neither primary document is available. Severity: high for E1 because the model's Calibration uses it; medium for E7.
4. **Accounting language.** The model says "simplified IFRS 9: no staging" and the book discusses IFRS 15 and IFRS 9 treatment. The required statement that this is an analytical modelling treatment and not an accounting determination is not applied consistently, and model treatment is not systematically separated from accounting policy. Severity: medium.
5. **The 10% affordability threshold.** The model labels it an "illustrative policy threshold", but the book refers to "the 10% threshold" in several places without that label. Severity: medium.
6. **"Utility" wording.** "Utility like service provider" is used in places, but the Chapter 1 title and several sentences say "utility". Severity: low, but it should be fixed for consistency.
7. **Provenance labels.** No consistent labelling of MODEL ASSUMPTION, COMPANY DATA, EXTERNAL EVIDENCE, CALIBRATED ASSUMPTION or UNVERIFIED across the inputs or the book. Severity: medium.
8. **Static outputs.** The Sensitivity table holds values computed outside the workbook. It is labelled, but it breaks the "no unexplained hardcoded outputs" test, and it goes stale whenever inputs change. Severity: medium.
9. **Front end.** The Dashboard is thin; there is no Start page; the Contents index is incomplete. Severity: medium (commercial quality).
10. **Checks coverage.** There are 25 integrity tests. Several requested reconciliations are not yet explicit tests: equity roll-forward, debt roll-forward, receivables roll-forward, cohort totals equal portfolio totals, RBF claims and payments. Severity: medium, to be confirmed in Phase 3.
11. **Excel and LibreOffice opening untested.** All validation so far used an independent formula engine. Severity: medium until tested.
12. **Branding and numbering.** The repository lists six volumes (1 Mini-Grids, 3 Clean Cooking and so on). The fixed series in the brief is Book 1, Bankable Is Not Enough; Book 2, PAYGo Solar Finance; Book 3, Bankable Hydro. Book 2 keeps its number either way, but the series description must change. Severity: low technically, high for the brand.
13. **Readiness results.** The default model reads 3 of 23 gates and the SolaraPay case 5 of 23. Both will be preserved; the work is to document the evidence behind each gate, not to change the counts.
