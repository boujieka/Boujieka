# Cobalt du Cameroun (2000–2025) : production, données miroir, projets, fiscalité

*Recherche documentaire du 31/10/2026, menée uniquement avec WebSearch : WebFetch, curl et Firecrawl n'étaient pas disponibles. Aucun PDF n'a été lu en entier. Tous les chiffres ci-dessous proviennent des extraits renvoyés par les recherches.*
*Étiquettes : **[F]** fait (texte primaire ou donnée chiffrée explicite) ; **[S]** source secondaire (presse, synthèse) ; **[C]** calcul.*
*Taux USD/XAF : Banque mondiale, colonne `taux_usd_xaf` de `docs/recherche-or-cameroun/valeurs_annuelles_or.csv`.*

---

## 0. Conclusion principale

- **Aucune production commerciale de cobalt n'a été enregistrée au Cameroun entre 2000 et 2025.**
  - L'USGS classe le cobalt parmi les ressources « non développées » du Cameroun. [S]
  - Le BGS indique que le gisement de Nkamouna « n'a pas encore été exploité ». [S]
  - La presse camerounaise de 2025-2026 écrit que le gisement « n'a jamais produit un gramme de cobalt » en 23 ans. [S]
- **Données miroir : deux traces seulement, minimes et contradictoires**, toutes deux pour 2023 et la Chine, sous le code SH 2605.
- **Aucune perte fiscale sur des flux réels n'a été publiée.** Les montants cités sont :
  - des projections : 200 M USD par an de recettes « attendues » ;
  - des sommes engagées dans le projet : capitaux de la SNI, pertes d'exploitation de Geovic.
