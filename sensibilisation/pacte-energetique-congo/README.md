# Le courant pour tous ? — le Pacte national énergétique en BD

Bande dessinée de sensibilisation (13 planches, silhouettes) destinée à la société civile, tirée du
*Pacte National Énergétique de la République du Congo* (Mission 300, septembre 2025, 37 pages).

- `index.html` : l'album complet (planches + notes « Ce que dit le Pacte », questions pour la causerie, sources et limites).
- `export/planche-XX.png` : chaque planche en 1080 × 1080 px, prête pour WhatsApp, Facebook ou l'impression.
- `export/pacte-energetique-congo-bd.pdf` : l'album en A4, une planche par page.
- `export.mjs` : régénère les PNG et le PDF (`node export.mjs`, nécessite Playwright).

Tous les chiffres viennent du Pacte ; chaque planche cite sa page. Les personnages sont fictifs.
Les incohérences internes du document (taux d'accès, montants) sont signalées dans la section « Sources et limites ».
