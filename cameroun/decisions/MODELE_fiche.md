# Fiche de décision — [intitulé précis]

> Modèle. Aucune fiche n'est remplie à l'étape 1 : elles exigent le chiffrage de l'étape 3.
> Chaque champ chiffré cite un `source_id` ou un calcul dans `models/`. « À vérifier » est une réponse acceptable ; un chiffre non sourcé ne l'est pas.

| Champ | Contenu |
|---|---|
| Problème traité (id registre) | |
| Décision demandée | Formulation exacte, une phrase |
| Autorité compétente | Présidence / Gouvernement (ministère) / Parlement / CTD / institution indépendante |
| Base juridique | Texte existant ou à adopter — **à vérifier** au Journal officiel |
| Responsable et partenaires | Une entité responsable unique |
| Grandeurs à mesurer (situation de départ) | Valeur, année, source, méthode de mesure |
| Actions et calendrier | Immédiat / 100 jours / 1 an / 3 ans |
| Investissements et coûts | Initial et récurrent, fourchette basse–haute |
| Financement | Confirmé / envisagé / non couvert, par source (budget, dons, concessionnel, commercial, PPP avec engagements futurs) |
| Conséquences tarifaires ou fiscales | Qui paie, combien, quand |
| Protection des ménages / transition | Ciblage, coût, mécanisme |
| Résultats attendus | Indicateur, cible, échéance, méthode de mesure |
| Prérequis et capacités | |
| Risques et mesures correctives | |
| Redevabilité | Qui publie quoi, à quelle fréquence, qui contrôle |
| Niveau de preuve | Élevé / moyen / faible, justifié |
